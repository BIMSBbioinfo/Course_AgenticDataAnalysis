Item by item.

Q · 01
Bash · environment

Which best describes the PATH environment variable in Bash?

b A list of directories that the shell searches when you type a command.
Q · 02
Bash · shell startup

What is the role of .bashrc?

a A script run automatically each time a new interactive Bash shell starts.
Q · 03
Bash · permissions

What does sudo do?

c Runs a single command with elevated (root) privileges.
Q · 04
Bash · sessions

Which best describes tmux?

b A terminal multiplexer that keeps sessions alive after you disconnect from SSH.
Q · 05
Bash · exit codes

In Bash, what does an exit code of 0 conventionally mean?

c The command completed successfully.
Q · 06
LLM · reasoning models

What distinguishes a reasoning model (e.g. chain-of-thought or adaptive-thinking models) from a standard LLM?

b Before producing the final answer it generates intermediate reasoning steps, and can spend more compute on harder problems.
Q · 07
LLM · representation

What is a "token" in the context of an LLM?

b A sub-word unit of text that the model processes; pricing and latency scale with it.
Q · 08
LLM · mechanism

What does the attention mechanism allow a transformer to do?

a Weight relationships between tokens across the context, not only adjacent ones.
Q · 09
LLM · context window

Which best describes an LLM's context window?

b A fixed-size budget of tokens the model can attend to in one call — shared by the system prompt, conversation history, tool outputs, and the response.
Q · 10
LLM · tool use

How does a tool-using (function-calling) LLM actually "use" a tool?

b The model emits a structured tool-call block in its output; the surrounding runtime parses it, runs the tool, and feeds the result back into the next turn.
Q · 11
Architecture · hardware

Why does GPU memory (VRAM) matter for LLM inference?

b It limits the size of model and context that can be loaded on a single GPU.
Q · 12
Agents · structure

Which best describes "planning" in an agentic LLM system?

c Deciding the sequence of actions the agent will take to reach a goal.
Q · 13
Context · project files

What is the purpose of a CLAUDE.md file in a project?

c To provide project-specific instructions that are persistently injected into the agent's context.
Q · 14
Context · hygiene

What is the key difference between /clear and /compact?

a /clear wipes the conversation context entirely; /compact summarizes prior turns to free space (lossy).
Q · 15
Correctness · controls

An LLM agent has built a single-cell RNA-seq pipeline that performs QC, doublet removal, clustering, and cell-type annotation. It runs to completion with exit code 0, but you suspect the results may be subtly wrong. Which combination of controls is best suited to catching silent failures in both directions?

c One reference sample with a known cell-type mixture (the pipeline must recover it) plus one empty-droplet sample (the pipeline must not call any cells).
